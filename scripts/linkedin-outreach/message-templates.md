# LinkedIn Message Templates — Kompound Commerce

> **Rules**: Keep connection request notes under 300 characters. Be human, not salesy. Reference something specific about their profile. Always lead with value.

---

## Connection Request Notes (under 300 characters)

### Template 1 — Fellow Seller Angle
```
Hey {FirstName}, saw you're building a brand on Amazon — really cool. I run Kompound Commerce, we help Amazon sellers scale with PPC and listing optimization. Would love to connect and share notes.
```

### Template 2 — Content Hook
```
Hi {FirstName}, I noticed you're in the Amazon FBA space. We just published a guide on cutting ACOS by 30%+ that a lot of sellers found useful. Happy to share if you're interested — let's connect!
```

### Template 3 — Group Connection
```
Hey {FirstName}, we're both in {GroupName}. Always great to connect with fellow Amazon sellers. I run an agency focused on helping small brands scale on Amazon & Walmart. Let's link up!
```

### Template 4 — Tool/Calculator Hook
```
Hi {FirstName}, saw you're selling on Amazon. We built a free FBA profit calculator that's been really popular with sellers — happy to send the link. Let's connect!
```

### Template 5 — Walmart Expansion Angle
```
Hey {FirstName}, noticed you're doing well on Amazon. Have you looked at expanding to Walmart? We've been helping sellers do exactly that — would love to connect and chat.
```

### Template 6 — Specific Pain Point
```
Hi {FirstName}, saw your post about {specific_issue}. We deal with this a lot at our agency — have some thoughts that might help. Mind if I share?
```

## First Follow-Up Messages (after they accept connection)

### Message A — Value-First Approach
```
Hey {FirstName}, thanks for connecting!

Quick question — what's been the biggest challenge in your Amazon business lately?

We work with a lot of sellers in the {their_niche/category} space and I've been seeing some common patterns. Happy to share what's working if it's helpful.

No pitch, just genuinely curious. 🤙
```

### Message B — Free Resource Offer
```
Thanks for connecting, {FirstName}!

Noticed you're selling {product_category} on Amazon. We actually just put together a free guide on {relevant_topic — e.g., "optimizing PPC for supplements sellers" or "listing SEO for home & kitchen"}.

Want me to send it over? No strings attached — we publish a ton of free content for sellers.
```

### Message C — FBA Calculator Hook
```
Hey {FirstName}, glad we connected!

Not sure if this is useful, but we built a free FBA profit calculator that breaks down your true margins after all Amazon fees. A lot of sellers have told us it helped them spot products that were actually losing money.

Here's the link if you want to check it out: https://www.kompoundcommerce.com/tools/fba-calculator.html

What are you selling these days?
```

### Message D — Quick Win Offer
```
Hey {FirstName}, thanks for accepting!

Quick thought — I took a glance at your brand on Amazon (hope that's okay). Noticed a couple of quick wins on your main listing that could help with conversions.

Would it be weird if I shared them? Totally free, just like helping sellers out.
```
