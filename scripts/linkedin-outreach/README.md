# LinkedIn Seller Outreach System — Kompound Commerce

A systematic approach to finding and connecting with small Amazon sellers on LinkedIn to offer Kompound Commerce's marketplace growth services.

## Quick Start

1. **Find sellers** using the search strategies in `search-strategies.md`
2. **Pick the right message** from `message-templates.md` based on the seller's situation
3. **Log every touchpoint** in `outreach-tracker.csv`
4. **Follow up** using the cadence outlined in `follow-up-cadence.md`

## Daily Workflow

| Time Block | Activity | Target |
|---|---|---|
| 15 min | Search & identify prospects | 15–20 new profiles |
| 20 min | Send connection requests (with note) | 10–15 requests |
| 15 min | Follow up with pending connections | 5–10 messages |
| 10 min | Engage with prospect posts (like/comment) | 10+ interactions |

## LinkedIn Limits (stay safe)

- **Connection requests**: 20–25/day max (start with 10–15/day for new accounts)
- **Messages**: 50–75/day max to existing connections
- **Profile views**: 80–100/day
- **Pending invitations**: Keep under 500 total; withdraw stale ones weekly
